Coloque os logos dos clientes nesta pasta.

Sugestões:
- Use arquivos `.png`, `.svg` ou `.webp`
- Prefira fundo transparente
- Altura visual parecida entre os logos ajuda o carrossel a ficar mais bonito

Exemplos de nomes:
- `cliente-01.png`
- `cliente-02.svg`
- `cliente-03.webp`

Depois de colocar os arquivos aqui, eu ligo eles no array `clientLogos` em `src/App.tsx`.
